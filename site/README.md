# Red Solution & Limkorm «Подарки всем»!

Промосайт акции: HTML5, CSS3 и vanilla JavaScript, без фреймворков и сборки. Это фронтенд-сборка концепта для согласования. Регистрация чеков и другие серверные функции работают в демонстрационном режиме.

## Как открыть

Вариант 1 — локальный сервер (рекомендуется, так работает копирование промокода):

```bash
cd site
python3 -m http.server 8000
# открыть http://localhost:8000
```

Вариант 2 — открыть `site/index.html` двойным щелчком. Всё работает, кроме записи в буфер обмена: вне `localhost`/HTTPS кнопка «Скопировать промокод» выделяет код и просит скопировать его вручную.

## Структура

```
site/
├── index.html            разметка, SVG-спрайт иконок, диалоги

    ├── fonts/            Onest (woff2, кириллица + латиница), локально
    ├── img/              hero-pets.webp, pets.webp, red-solution.png, логотипы магазинов, favicon, og-cover.jpg
```

Секции: шапка → hero → как участвовать → бренды (4) → где купить → подарок каждому → призы (6) → победители и квиз-тизер → квиз → условия → FAQ (10 вопросов) → финальный CTA → подвал.

## Проверено

- Ширины 360, 390, 768, 1024, 1440 px: нет горизонтальной прокрутки, все изображения загружаются, ошибок в консоли нет.
- Мобильное меню: открытие/закрытие, `aria-expanded`, Escape с возвратом фокуса, закрытие по клику вне панели и по ссылке.
- Якорные переходы с учётом липкой шапки; подсветка текущего раздела в навигации.
- Форма чека: инлайн-ошибки, фокус на первое ошибочное поле, выбор файла, демо-состояние после отправки, сброс при повторном открытии.
- Диалоги «Правила», «Политика», «Поддержка»; закрытие по кнопке, фону и Escape.
- FAQ: 10 вопросов, первый открыт, одновременно открыт один ответ (`<details name>`).
- Квиз: 3 шага, «Назад», результат, «Пройти заново».
- Копирование промокода и тост.
- Accessibility-аудит axe: 0 нарушений. Контраст текста — не ниже 4.5:1.
- `prefers-reduced-motion`: вход hero и смещения отключаются, оверлеи появляются коротким затуханием 150 мс. Анимируются только `transform` и `opacity`; автоматического движения дольше 5 секунд нет.

## Демонстрационные функции (требуют подключения)

| Функция | Сейчас | Что нужно |
| --- | --- | --- |
| Регистрация чека | Форма проверяет поля и показывает демо-состояние, данные не отправляются | API приёма и проверки чеков (ОФД / сервис проверки), формат и лимиты файлов, антифрод |
| Авторизация / личный кабинет | Отсутствует (нет в итоговом макете) | Способ входа, хранение заявок участника |
| Выдача промокода LIMKORM | Код показан на странице всем | Решение: общий код или персональные коды по зарегистрированному чеку |
| Победители | Пустое состояние «Результаты появятся после розыгрышей» | Источник данных, формат публикации, маскирование персональных данных |
| Квиз | Ответы хранятся только в памяти страницы | Утверждённые вопросы и связь с акцией (если нужна) |
| Правила, политика, поддержка | Информационные окна-заглушки | Документы (PDF/страницы) и контакты поддержки |
| Telegram-бот | Не реализован | Бот и ссылка на него |
| Аналитика, cookie-баннер | Нет | Счётчики (Яндекс Метрика и др.) и уведомление о cookie по 152-ФЗ |

## Недостающие условия акции

Без них сайт нельзя запускать как действующую акцию:

1. Юридический организатор и оператор персональных данных.
2. Даты: период покупок, регистрации чеков, розыгрышей, выдачи призов.
3. Официальные правила акции (документ).
4. Перечень участвующих товаров (артикулы) и площадок покупки.
5. Ограничения: минимальная сумма, количество чеков на участника, повторное участие.
6. Количество каждого из шести призов и порядок их выдачи.
7. Способ определения победителей и публикации результатов.
8. Условия промокода LIMKORM: срок действия, исключения, совместимость с другими скидками, порядок получения.
9. Политика обработки персональных данных и согласие на обработку.
10. Контакты поддержки участников.

## Перед публикацией

- Указать утверждённую дату старта в `data-start` у счётчика (`[data-countdown]` в `index.html`). Сейчас стоит условная дата 1 декабря 2026, 00:00 по Москве.
- Удалить `<meta name="robots" content="noindex, nofollow">` из `index.html`.
- Указать абсолютный URL в `og:image` и добавить `<link rel="canonical">` с боевым доменом.
- Заменить растровый логотип RED SOLUTION на векторный SVG, экспортированный из `materials/Rs/RED SOLUTION_logo.eps`.
- Заменить текстовый знак OZON на официальный логотип Ozon.
- Заменить формулировку в подвале «Макет для согласования…» на юридическую информацию организатора.
- Подтвердить шрифт: Onest использован как близкий гротеск; точный фирменный шрифт клиента не установлен.
