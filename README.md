## О проекте

Лендинг совместной акции производителя кормов **LIMKORM** (AJO, SIRIUS, «Одно Мясо», «Наш Рацион») и бренда техники **RED SOLUTION**. Акция идёт с 1 ноября по 26 декабря 2026 года. Каждый участник получает промокод LIMKORM на скидку 1 000 ₽, а среди участников разыгрывают 58 призов.

Сайт собран без фреймворков и сборки: HTML5, CSS3 и vanilla JavaScript. Единственная библиотека — GSAP для сцены с бегающими питомцами, она лежит рядом с кодом.

## Что внутри

- **Hero с гарантированным подарком**: промокод LIMKORM со скидкой 1 000 ₽ от 3 000 ₽ и кнопка копирования.
- **Как участвовать**: три карточки, у последней своя тёмная тема и фото приза.
- **Бренды**: сцена на GSAP, где питомцы бегают за упаковками; есть кнопка паузы.
- **Где купить**: Ozon, Wildberries, Яндекс Маркет.
- **Призы**: 9 товаров RED SOLUTION, 58 призов, два розыгрыша (1 и 26 декабря 2026).
- **Форма регистрации чека** с проверкой полей и демо-состоянием отправки.
- **Победители и квиз о питомцах**.
- **FAQ** на `<details name>`: одновременно открыт один ответ.
- **Счётчик до старта акции** с датой старта; скрывается после 1 ноября и по кнопке.

## Технические решения

| Тема | Решение |
| --- | --- |
| Стек | HTML5, CSS3, vanilla JS; без сборки и зависимостей, GSAP 3.12.5 лежит локально |
| Дизайн-система | CSS-переменные: цвета, шкала шрифта на `clamp()`, радиусы, отступы |
| Палитра | оранжевый `#f5a211`, графит `#151515` / `#1a1a1a`, кремовый `#fbf5ec` |
| Шрифт | Onest (кириллица и латиница), локальные woff2 |
| Адаптив | mobile-first; проверено на 375, 768, 1024 и 1440 px, горизонтальной прокрутки нет |
| Анимация | только `transform` и `opacity`; `prefers-reduced-motion` учтён; автоматическое движение дольше 5 секунд ставится на паузу |
| Доступность | семантическая вёрстка, видимый фокус, `aria`-атрибуты в меню, диалогах и FAQ, контраст не ниже 4.5:1 |
| Изображения | WebP, заданные `width` и `height`, `loading="lazy"` ниже первого экрана |
| SEO | `title`, `description`, Open Graph, favicon |

Подробности про ассеты и проверенные сценарии — в [site/README.md](site/README.md).

## Запуск локально

```bash
cd site
python3 -m http.server 8000
# открыть http://localhost:8000
```

Сайт можно открыть и двойным щелчком по `site/index.html`, но копирование промокода в буфер обмена работает только с `localhost` или по HTTPS.

## Публикация

Сайт выкладывается на Netlify из этого репозитория. Настройка лежит в [netlify.toml](netlify.toml): публикуется папка `site`, сборки нет.

## Демо-режим

Это фронтенд-сборка для согласования. Регистрация чеков, победители и квиз работают в демонстрационном режиме и ничего не отправляют на сервер. Что нужно подключить для запуска, описано в [site/README.md](site/README.md).
